Method. The AI Agent's own request (its instructions, the four document images and the answer schema) went to every model through the LLM Foundry gateway: Claude by the Anthropic API as the agent calls it, GPT and Gemini by the gateway's OpenAI-compatible routes with the schema in the instructions. The documents are the console's drawn specimens of the client's reconciliation log, so what each one prints is known exactly; some photos are spoiled on purpose. Fields read right: ten printed values on the clean photos (passport names, date of birth, nationality, number, expiry; secondary ID name and date of birth; proof-of-address address and date). Decisions: the console's fixed checks run on each model's read, against the same checks on the right read (pass, or a person). Cost is the tokens each call used at list price. {{ bench.price_sources }} A small sample: read the differences of a point or two as noise. Rerun with python -m fincrime.benchmark.
